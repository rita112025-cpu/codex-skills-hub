來源與安全說明

Codex Skills Hub 是導航與索引網站，本身不會自動安裝 Skill。

  • 資料主要整理自 ComposioHQ/awesome-codex-skills，僅整理名稱、分類、用途、風險與依賴，完整實作請查看原 repo 的 SKILL.md 與 scripts/。
  • 網站顯示的安全資訊只是依公開 repository 及 Skill 內容整理，不代表完整安全稽核。
  • 安裝第三方 Skill 前，仍應自行查看 SKILL.md、scripts 與相關權限，確認是否包含 git write / delete / network / API Key / MCP 等操作。
  • 安裝方式為複製指令後貼到終端機自行執行，不會在網頁內執行 Shell。
  • 未確認欄位標示為 null 或 未確認，不會把未查到寫成沒有。
